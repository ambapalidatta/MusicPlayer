# MusicPlayer

# 🎵 Simple Music Player

A visually appealing and responsive web-based music player built using HTML, CSS, and JavaScript. This project allows users to play, pause, and scrub through audio tracks with an elegant UI.

## 🚀 Features

- 🔊 Play/Pause functionality
- 🎚️ Custom progress bar with seek support
- 🎵 Embedded audio with artist and song name
- 📱 Responsive and stylish UI with icons
- 🎨 Modern design using Font Awesome & CSS animations

## 📁 Project Structure

```
/your-project-directory/
├── index.html         # Main HTML structure
├── style.css          # Stylesheet for music player
├── script.js          # JavaScript for controlling audio
└── Media/
    ├── Despacito.mp3  # Sample music file
    └── Thumbnail.png  # Song thumbnail image
```

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome (for icons)

## 💡 How to Use

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/music-player.git
   cd music-player
   ```

2. Add your own audio files and thumbnail images in the `Media/` folder if desired.

3. Open `index.html` in your web browser:
   ```bash
   open index.html
   ```


## 📌 Notes

- You can replace `Despacito.mp3` with any other `.mp3` file. Just update the `<source>` in the HTML accordingly.
- Make sure to use `.mp3` format for browser compatibility.
